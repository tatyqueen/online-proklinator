# Онлайн-проклинатор — Суд ведьм v4

Откройте index.html или опубликуйте содержимое папки в корне GitHub Pages.

Работают: анимированная заставка, Суд ведьм, апелляция, встречный иск, ссылка на дело (#case=...), каталог проклятий, гадания, ритуалы, PNG, архив.

Важно: ссылка на дело содержит имя и текст обвинения в URL; не используйте реальные личные сведения. Базы данных и платного API нет.

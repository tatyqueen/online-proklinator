# Проклинатор душ — оформление и команды

Имя: **Проклинатор душ | Тайная канцелярия**

Краткое описание: **Две ведьмы, кот-аудитор и персональные шуточные документы. Только юмор. Покупки — за Telegram Stars.**

Описание:

> 🔮 Татьяна разбирается. Екатерина оформляет последствия. Кот-аудитор ставит печать.
>
> Выберите пакость, придумайте прозвище и ситуацию — получите персональный шуточный документ.
>
> ⭐ Разовая оплата Telegram Stars, без подписки.
> 🧾 Покупки сохраняются за вашим Telegram-аккаунтом.
> 💬 Помощь: /paysupport.
>
> Всё вымышлено. Никакого реального воздействия на людей.

## Команды

- `/start` — обложка, знакомство, кнопки каталога и покупок.
- `/purchases` (также `/orders`) — последние 8 заказов владельца, переход ко всей истории.
- `/order p_…` — текст оплаченного документа, только для его владельца в личном чате.
- `/help` — навигация.
- `/paysupport номер описание` — обращение поддержки; обычный текст в личном чате также сохраняется в очередь.
- `/terms`, `/privacy` — ссылка на действующее уведомление, правила и канал запроса по данным. Окончательные юридические документы ещё не утверждены.

После `successful_payment` бот отправляет уведомление с названием, суммой, номером заказа и кнопкой результата. Это сервисное сообщение, не рекламная рассылка. Реального тестового сообщения произвольному адресату при настройке не отправляется.

Повторные webhook-события используют ключ `paid:<orderId>` или `command:<updateId>` в `bot_outbox`. Успешные отправки не повторяются. Временная ошибка отправки возвращает ошибку webhook, чтобы Telegram повторил доставку; блокировка бота пользователем отмечается `blocked`. При сетевом сбое после фактической доставки, но до записи её подтверждения, повтор сообщения всё же возможен: Bot API не даёт универсальной идемпотентности sendMessage. Покупка от этого не дублируется. Постоянного фонового планировщика пока нет — не утверждать гарантированную доставку вне окна повторов Telegram.

Проверка неотправленных сообщений:

```sql
SELECT event_key,status,attempts,created_at FROM bot_outbox WHERE status<>'sent';
```

## Изображения

- `assets/bot-cover.jpg` — обложка в приветственном сообщении `/start`.
- `assets/bot-avatar.jpg` — аватар с котом-аудитором, устанавливается через Bot API.

1. **Обложка:** сохранить узнаваемые лица Татьяны слева с шаром и Екатерины справа с поднятой рукой, кота в центре; магическая канцелярия, сливово-чёрный фон, розовый свет, золото свечей; горизонтальная композиция 16:9; точный заголовок «ПРОКЛИНАТОР ДУШ», подзаголовок «Тайная канцелярия мелких пакостей»; без мелких боковых текстов, юмористическое фэнтези.
